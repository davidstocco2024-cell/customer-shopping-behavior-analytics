# Customer Shopping Behavior Analytics 🛒📊

Un proyecto integral de análisis de datos que explora los patrones de consumo de los clientes, combinando **Python**, **SQL (PostgreSQL)** y **Power BI** para transformar datos transaccionales en *insights* de negocio accionables.

## 🚀 Stack Tecnológico
* **Lenguaje:** Python (Pandas, Jupyter Notebooks)
* **Base de Datos & Consultas:** PostgreSQL, SQL Server
* **Visualización & BI:** Power BI (`.pbix`)
* **Control de Versiones:** Git & GitHub
