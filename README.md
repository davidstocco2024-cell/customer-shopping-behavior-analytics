# Customer Shopping Behavior Analytics 🛒📊

A comprehensive data analytics project exploring customer purchasing patterns, combining **Python**, **SQL (PostgreSQL)**, and **Power BI** to transform transactional retail data into actionable business insights.

![Power BI Dashboard View](powerbi_dashboard.png)

## 🚀 Tech Stack
* **Language:** Python (Pandas, Jupyter Notebooks)
* **Database & Querying:** PostgreSQL, SQL Server
* **Visualization & BI:** Power BI (`.pbix`)
* **Version Control:** Git & GitHub

---

```text
customer-shopping-behavior-analytics/
```

---

## 📈 Key Findings & Features
* **Global KPIs:** Tracking Total Revenue ($233,081), Average Purchase Amount ($59.76), Average Review Rating (3.75), and Total Customer Count (3,900).
* **Advanced Segmentation:** Customer behavior analysis focused on age groups, gender distribution (67.74% Male / 32.26% Female), and subscription status (27% Subscribers / 73% Non-Subscribers).
* **Category & Product Performance:** Clothing leads overall category sales ($104,264), with top revenue items including Blouses ($10,410), Shirts ($10,332), and Dresses ($10,320).

---

## 📊 Visualization (Power BI)
The report features a clean, executive-ready design:
* **Top KPI Cards:** Instant visibility into overall revenue, customer base, order averages, and rating scores.
* **Demographic Breakdown:** Revenue and customer distribution segmented by age group, gender, and subscription status.
* **Interactive Slicers:** Dynamic filtering capabilities by payment method, shipping type, category, and subscriber status.

## ⚙️ How to Run
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/davidstocco2024-cell/customer-shopping-behavior-analytics.git
   ```
2. Open `customer_shopping_behavior.ipynb` in Jupyter Notebook to review the data processing and analysis workflow in Python.
3. Explore the `sql/` folder to inspect database queries and data transformations.
4. Launch `powerbi/dashboard.pbix` in Power BI Desktop to interact with the visual dashboard.
